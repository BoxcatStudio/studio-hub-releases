# Studio Hub

Boxcat Studio's tools app for artists. This repository holds the installers only.

## Download

**[StudioHub-Setup.exe](https://github.com/BoxcatStudio/studio-hub-releases/releases/latest/download/StudioHub-Setup.exe)** (Windows 10/11, always the newest version)

## Install

1. Run `StudioHub-Setup.exe`. No admin rights needed.
   If Windows says **"Windows protected your PC"**, click **More info**, then **Run anyway**.
2. To make shaders with Mira, install Claude Code from [code.claude.com](https://code.claude.com).
   The first time, Mira shows **Sign in with Claude**: sign in with your own account.

## Updates

Automatic. Studio Hub checks when it opens and every hour, and downloads quietly.
When **Update ready** appears in the title bar, click it: it installs and restarts.
You never need to uninstall or reinstall. Your settings and the shader library are never touched.
